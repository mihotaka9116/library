My Poem - Digital Library
拾い集めた言葉の欠片を、一冊の本のように。

心に留まった詩や名言を、デジタルな「本」としてアーカイブしたポートフォリオサイトです。

📋 Concept
「My Poem」は、日々の生活や読書の中で出会った、自分を立ち止まらせてくれる言葉たちを大切に保管するための私的な図書室です。
ただ言葉を並べるだけでなく、「本を開く」という体験を通じて、その言葉の背景や制作者自身の想い（Reflection）に触れられるような構成を目指しました。

✨ Features
Interactive Book Grid: CSS 3D Transforms を活用し、マウスホバーで本が開くような立体的なアニメーションを実装。

Poem Modal: 本をクリックすると詳細な内容が表示。左側に書影、右側に引用文と「自身の想い」を配置した美しいエディトリアル・デザイン。

Authors Section: 寺山修司や室生犀星など、影響を受けた著者のプロフィールを、モノクロからカラーへ変化する視覚効果とともに紹介。

Scroll Animations: AOS (Animate On Scroll) ライブラリを導入し、スクロールに合わせてコンテンツが滑らかに浮き上がる演出。

Responsive Layout: iPad mini やスマートフォンなどの各種デバイスに最適化。モバイル環境では要素を中央寄せにし、可読性を向上。
